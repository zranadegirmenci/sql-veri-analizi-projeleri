# SQL ile İlişkisel Veritabanı ve İş Analitiği Portfolyosu

Bu depo; ilişkisel veritabanı mimarisi, SQL sorgulama teknikleri ve veri tabanlı iş zekası modellemesini kapsayan analitik vaka çalışmalarını içermektedir.

---

## 📁 Proje: Müşteri Davranışları ve Satış Performansı Analitiği
* **Dosya:** `sql_ile_musteri_ve_satis_analitigi.ipynb`
* **Odak:** Müşteri sipariş frekansları, sepet büyüklükleri, VIP segmentasyonu ve kategori içi harcama derecelendirmesi.
* **Kullanılan SQL Yetkinlikleri:**
  * **İlişkisel Bütünlük:** `CREATE TABLE`, `PRIMARY KEY`, `FOREIGN KEY`
  * **Birleştirme & Agregasyon:** `INNER JOIN`, `GROUP BY`, `SUM`, `AVG`, `COUNT`
  * **Filtreleme:** `HAVING` vs `WHERE` koşulları ile kural tabanlı segmentasyon
  * **Pencere Fonksiyonları (Window Functions):** `DENSE_RANK() OVER(PARTITION BY ... ORDER BY ...)`
